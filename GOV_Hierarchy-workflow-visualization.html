01输入与预检
CSV/XLSX→必填列→行政区划→稳定模板→输出目录
✓ 目标文件可读　✓ 必填列齐全　✓ 模板可读　✓ 输出目录可写 → preflight = pass，进入常规校验
02读取参考数据
目标 CSV/XLSX→行政区划 CSV→稳定模板 CSV

读取目标输入、行政区划和稳定隶属关系模板。输入保留行号和工作表；行政区划用于地名解析，模板用于后续建立关系索引。

输入：贵州.csv 行政区划：中国行政区划-行政级别结果.csv 稳定模板：北京-隶属关系模板.csv
03标准化记录
级别列构造链路→行政区路径→名称抽象→类型/后缀/键

依行政级别列构造父子节点链，生成 SystemKey 与 chain_key；行政区候选按更深层级、名称更长、正式名优先选择。地名替换为占位符，常用简称统一，再识别单位类型和后缀。

云岩区市场监管局 → 云岩区 / 贵州省-贵阳市-云岩区 → {{省级行政区}}{{县级行政区}}市场监督管理局 → 单位类型：市场监管局；SystemKey：中共中央
04构建模板索引
精确边索引→子模板允许父集合→类型弱匹配规则→系统索引

稳定模板被转换为内存索引：精确父子边用于强匹配，子模板反查用于识别父模板不符，父模板+子单位类型用于弱匹配，系统索引用于前置系统检查。

精确边索引键： SystemKey + 父单位模板 + 子单位模板 → 用于后续唯一边的快速关系判断
05拆边与唯一边去重
chain_key→相邻节点成边→edge_key 去重→校验一次→回填多链

edge_key 包含系统、父子行政区路径、关系类型、父子级别、抽象模板与单位类型；并非“类型相同”就可复用。语义一致的边只校验一次，保证相同关系得到一致结果。

链路 A：省政府 → 市政府 → 区政府 链路 B：省政府 → 市政府 → 区政府办公室 共享边：省政府 → 市政府（只校验一次，结果回填 A、B）
06唯一边关系校验
系统/行政区前置→精确边→等价边→父模板反查→类型规则

精确不命中时才尝试安全等价；如果子模板存在但当前父模板不在允许集合，输出 PARENT_TEMPLATE_MISMATCH，不会退化成弱匹配。

{{省级行政区}}{{县级行政区}}人民政府 → {{省级行政区}}{{县级行政区}}市场监督管理局 → 精确命中：通过
07聚合输出与验收
边级结果→最严重结论聚合→CSV/XLSX→JSON/MD 汇总→输出验收

任一硬失败边使链路“不通过”；无硬失败但有类型弱匹配为“弱通过”；其余为“通过”。写出后还要验证文件存在、非空与关键字段齐全。

边 1：精确匹配（通过） 边 2：类型弱匹配（弱通过） → 整条链路：弱通过

08人工核验与模板治理

对失败和弱通过项进行人工核验后，只有被明确批准且经回测证明安全的关系，才能进入稳定模板。

人工核验→ approved 筛选→ 候选规则摘要→ 回测对比→ 落模板门槛
